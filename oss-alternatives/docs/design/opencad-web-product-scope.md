# OpenCAD Web 产品范围与验收契约

## 产品决定

2026-10-11 用户再次明确：交付浏览器访问的 Web 服务，以 CATIA /
SolidWorks 的完整能力范围为长期目标，不开发面向用户的独立本地安装包。
这与 2026-10-06 Web-only 决策一致。保留桌面材料作为历史及回归资产，
不删除旧代码，不把 Windows 构建、签名或安装当作 Web 发布前提。

本件是开发契约，不是完成清单或公开竞品认证。目标不能缩减成几项实体
操作，也不能用菜单、操作注册名、元数据记录或小模型测试冒称全功能。
服务器部署所需的容器/依赖不是面向最终用户的桌面产品。

## 当前能力与差距

下表是 2026-10-11 源码审计，不是新增功能已经实测通过。

| 域 | 已有基础 | 尚未收项的真实工作流 |
|---|---|---|
| Web 服务 | HTTP、浏览器、原子实体修改、发布检查点 | 用户/项目隔离、鉴权、可靠最新版本持久化、冲突/协作协议、任务排空 |
| 草图 | 二维几何、约束残差与自由度计算 | 圆弧/样条完整求解、拖动、矛盾/冗余诊断和完整 Web 编辑 |
| 参数零件 | 真 FreeCAD/BRep 拉伸、旋转、布尔、扫掠、放样、圆角、抽壳等 | 统一下游重建、表达式/配置/设计表、工业持久拓扑引用、复杂退化鲁棒性 |
| 曲面 | 受限闭合截面扫掠/放样 | 精确 NURBS、开放曲面、导引线、G1/G2、裁剪/缝合/修复/增厚 |
| 装配 | 位姿/参考记录、凸包围盒干涉、配合残差分析 | 独立真实零件加载、拾面配合、应用全组求解、真实BRep碰撞与层级装配渲染 |
| 工程图 | 一部分真隐藏线、剖视、PDF/DXF | 纯旋转/STEP/装配通路、真实材料剖面、关联更新、BOM/GD&T/MBD |
| 钣金/焊件 | 通用实体算子可复用 | 折弯补偿/展开复折、结构截面/端部修剪、切割清单、联动修改 |
| 制造/CAM | 尚无闭环实现证据 | 毛坯/刀具/坐标、真实刀轨、后处理、独立NC去料/碰撞验证 |
| 电气/管路 | 尚无闭环实现证据 | 原理图/线束/管路、器件连接、空间路径、规则校验、BOM与机电联动 |
| 仿真 | 真实悬臂梁有限元、质量弹簧阻尼算例 | 任意带孔CAD网格、材料/边界拾取、异步作业、接触/非线性/运动/多物理域 |
| 数据管理 | 单图L1文本和保存/恢复接口 | 私人/共享项目、版本/分支/审查、配额、权限/审计、PDM到PLM扩展 |
| 交互/规模 | WebGL小模型和视图控制 | 边/面/组件拾取、LOD/实例化、渐进传输、大装配与低端设备预算 |

特别禁止：抽壳不等于钣金，扫掠不等于焊件，包围盒干涉不等于真零件
碰撞，算例通过不等于任意 CAD 仿真，编号不等于持久拓扑命名，
文件存储不等于完整 PLM。

## Web 架构边界

浏览器负责交互、相机和客户端 GPU 渲染；服务端负责权限、项目版本、
几何事务、持久存储和任务执行。真实几何不能以网格视觉近似替代。
当前 CPU 内核与 WebGL 分工不因服务器有 RTX 3080 自动改变。

客户端 GPU 是访问者机器上的 GPU。服务器 RTX 可用于明确实现且独立
验收的离屏渲染/缩略图/视频/远程画面，或合适的批量计算；不能据服务器
上启动的浏览器 renderer 推断远端浏览器也获得服务器 GPU 加速。
本件不新增 GPU 作业、不宣称加速倍数。

服务化必须先定义并验证以下契约，之后才向多用户产品发布升级：

1. 身份、项目归属与授权；维护接口仅管理员可用，业务直连不能绕过权限。
2. 每项目独立文档和历史，每用户独立语言/偏好；匿名演示与私人编辑明确分离。
3. 文档ID、提交版本、预期基版本；过期编辑显式冲突，state/mesh绑定同一版本。
4. 确认成功的编辑具备持久边界；崩溃后不退回旧发布检查点。
5. 所有GET业务只读；打开/切换图纸不能被预取请求清空共享历史。
6. 有界作业队列、配额、幂等提交ID、可查询终态和真实取消语义。
7. 退出前停止接单、排空/终止有据、已提交版本落盘；不靠daemon线程保证安全。

当前这些是明确未完成的契约，不是已常驻的安全保证。现存单工作区不能
被包装为生产级多租户服务；不要用旧 CAD 门 PASS 给这一缺口背书。

## 分阶段收项

各阶段共同要求浏览器操作 -> HTTP -> 真内核/求解器 -> 保存重开 ->
独立产物解析，并覆盖单位、失效引用、非法输入及失败原子性负控。
所有证据绑定源码和模型，未采项单列，不由截图或返回 `ok` 代验。

1. Web正确性/安全：两个用户并行编辑、切语言、保存与撤销不串扰；
   匿名/越权拒绝，过期版本冲突，重复请求不重复造型；故障重启恢复最后确认版。
2. 工业参数零件：解析模型核体积/质心/孔/有效BRep，STEP往返；改上游
   草图后完整下游实体、工程图、mesh一致；拓扑分裂/合并必须正确迁移或显式失效。
3. 草图/曲面：独立残差和DoF验收约束；精确样条、导引放样、裁剪、
   缝合、增厚，分别量G0间隙/G1法向/G2曲率，不用视觉光顺代替。
4. 真实装配：两独立件拾面/轴配合，应用求解位姿，核固定件、残差、
   自由度；轴穿孔零相交、移至孔壁正相交，保存/撤销及冲突原子性成立。
5. 关联工程图：带孔件、纯旋转件、STEP件、装配均出图；模型修改后
   更新或明确标旧，PDF/DXF独立核孔/材料剖面/隐藏线/比例/标准和BOM数量。
6. 钣金/焊件：L/U件折弯展开解析值对拍、复折等厚，框架端部修剪；
   切割清单数量/长度/角度/质量核算，上游骨架编辑联动，不把属性当几何。
7. CAM/仿真：NC独立解释与去料回放核残料/过切/碰撞；带孔BRep保孔
   网格、材料/约束/载荷作业，核反力平衡与网格收敛，模型修改使旧结果失效。
8. 企业数据与规模：项目权限/版本/审批/审计、装配配置与交付；
   固定客户端GPU/浏览器/DPR/网络/模型集，测首屏、p95重建、帧时间、
   拾取延迟、内存与传输。样本按组件数、唯一几何和三角形数分档。
9. 电气/管路：原理图与三维器件同步、线束/管路沿真实空间路径布置；
   核连接性、最小弯曲半径、碰撞、长度/BOM和上游编辑联动，错误规则
   显式拒绝。原理图、三维Routing与更完整系统工程分别建模验收。

每个扩展物理域、制造工艺、标准和产品角色单独登记模型与门。
未逐项签收之前，“达到全功能水平”始终是目标，不是现状声明。

## 独立 Web 回归入口

`tools/cad3d/web_release_profile.py` 为新入口；不改旧十二阶段、
`run-gates.py`、桌面验收或 r8 冻结日志。

```bash
sudo -n -u infra python3 -B oss-alternatives/tools/cad3d/web_release_profile.py --list
sudo -n -u infra python3 -B oss-alternatives/tools/cad3d/web_release_profile.py --stage selftest
sudo -n -u infra python3 -B oss-alternatives/tools/cad3d/web_release_profile.py --stage contracts
sudo -n -u infra python3 -B oss-alternatives/tools/cad3d/web_release_profile.py --stage full
```

默认证据落 `/hf3fs-jd/data/tmp/opencad-web-profile-20261011/`。
一次运行复制一份隔离源码，保留Git已登记OSS源及当前OpenCAD新增源码，
不再永久排除原来的三个随包Web资源。源、副本、日志和判定均绑定摘要；
源码或门注册集合漂移报红。未知stage不能默默改跑numeric。

保留42个原Web相关门；明确退出 G11主腿、G24、G35、G36，记不适用，
退出的是桌面发行链，不改成PASS。G11.2以独立命令保留宿主Python staging源码闭包；
它不是Web部署载荷验证。G7静态跨平台CI质量检查与G5全OSS合规检查
仍保留，不声称因此验证了Windows运行或只审了OpenCAD。

判定 `OPENCAD_WEB_PROFILE verdict=PASS` 只表示当次所选回归范围成功。
`full_profile=false` 不是完整入口通过；`production_deployment`、
`multi_tenant_readiness`、`industrial_feature_parity` 均显式
`NOT_ASSESSED`，不能由回归PASS推导。此入口尚未接生产发布Hook，
不是常驻发布闸；真实部署/多用户安全的自动验收是下一项工程。

新增入口改变源码指纹，不能把r8结果追认为新指纹通过；新验证记录与
历史1834总项分开，不求和或重复计算。可选依赖skip原样留证，不删测试。

正式接受同次结果必须同时核对 `result.json`、`profile.log` 与进程退出码，
完整入口还需 `full_profile=true`、12阶段齐全、源码/副本零漂移。
终态JSON先发布 `PENDING`，正式日志成功后才原子发布终态；日志或原子
替换失败不能只读残留文件判通过。完整输出目录内保留的产物统一绑定摘要，
真数值JSON与云图显式放进该次阶段目录，截图绑定真实像素读取路径。
这个清单不包含工具已删除的临时求解文件或目录外产物，不能声称一切计算
中间件均已持久保留；最终JSON/日志本身需独立保存及核对。
